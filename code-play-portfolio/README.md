# Code & Play — Indie Developer Portfolio

A GitHub Pages version of the Code & Play portfolio. It includes the same sections, project descriptions, game links, email, and mobile number as the Wix site, with a responsive dark and lime visual theme.

## Publish with GitHub Pages

This repository contains several independent projects and already uses GitHub Pages from the repository root. The portfolio is served from its own folder, so it can coexist with the other pages.

The site URL is `https://75neel-ops.github.io/deepbluemonkey/code-play-portfolio/`. No Wix account or build step is required.

## Add it to your desktop

After the site is published, open it in Chrome or Edge and use the browser menu to choose **Install page as app** or **Create shortcut**. The included web app manifest and `icons/code-play-icon.svg` provide its Code & Play name, theme, and desktop icon. On a phone, use the browser's **Add to Home Screen** option.
